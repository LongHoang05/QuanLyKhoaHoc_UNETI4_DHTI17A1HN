# Auto Push Rule

When you finish making any code modifications or fixes to the duan36 project, you **MUST** automatically commit and push the changes to the 
tduong branch of the local Git repository located in the duan36 folder. 

**Steps to follow after a fix:**
1. Navigate to the duan36 directory.
2. Stage all changes: git add .
3. Commit with a descriptive message explaining the fix.
4. Push to the 
tduong branch: git push origin duong

*Note: Never push to the main branch. Only push to 
tduong.*
