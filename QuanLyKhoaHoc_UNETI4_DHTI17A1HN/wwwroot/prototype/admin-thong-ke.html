Chuẩn đầu ra UNETI
1. Doanh Thu Học Phí Theo Tháng (DoanhThuTheoThang)
Truy vấn: GroupBy(d => d.NgayDongHocPhi.Value.Month).Select(g => g.Sum(x => x.SoTienDaDong))
Đơn vị: Triệu VNĐ
var doanhThu = db.DangKyHocs.Where(d => d.SoTienDaDong > 0)
  .GroupBy(d => d.NgayDongHocPhi.Value.Month)
  .Select(g => new { Thang = "Tháng " + g.Key, TongThu = g.Sum(x => x.SoTienDaDong) })
  .OrderBy(x => x.Thang).ToList();
2. Đơn Theo Trạng Thái
Mục 9.6: GroupBy(d => d.TrangThai)
var tyLeDon = db.DangKyHocs
  .GroupBy(d => d.TrangThai)
  .Select(g => new { Status = g.Key, SoLuong = g.Count() });
3. Tỷ Lệ Lấp Đầy Sĩ Số Từng Lớp (TyLeLapDay)
Mục 9.6: SoHocVien / SiSoToiDa * 100%
var lapDay = db.LopHocs.Select(l => new {
  l.TenLop, TyLe = (double)l.DangKyHocs.Count(d => d.TrangThai == "Đã duyệt" || d.TrangThai == "Đã đóng học phí") / l.SiSoToiDa * 100
}).ToList();
4. Điểm Tổng Kết Trung Bình Theo Lớp (DiemTB)
Mục 9.6: Average(k => k.DiemTongKet)
var diemTB = db.KetQuaHocTaps
  .GroupBy(k => k.DangKyHoc.LopHoc.TenLop)
  .Select(g => new { Lop = g.Key, DiemTB = g.Average(x => x.DiemTongKet) })
  .OrderByDescending(x => x.DiemTB).ToList();
